# EduGuide AI — High-Fidelity UI/UX Prototype

A complete, professional, interactive front-end prototype for an AI-powered career
guidance platform serving secondary school, undergraduate and postgraduate students.

**No backend · No real AI · No database** — everything runs client-side with sample data.

---

## Quick Start

1. Clone or download the project folder.
2. Open `index.html` in any modern browser, **or** serve locally:

   ```bash
   npx serve .
   # or
   python3 -m http.server 8000
